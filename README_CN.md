## 主要发现

1. 认知水平和能力自信是最强预测因子 (r = 0.448, 0.423)
2. 学历悖论：低学历父亲参与度反而更高
3. 中介效应：能力自信中介42.5%的认知-参与关系
4. 夫妻一致性 (r = 0.267) 影响是配偶态度 (r = 0.119) 的2.2倍
5. **调节效应**：工作场所政策支持显著调节工作压力与父亲参与的关系（B = 0.230, p = 0.003, ΔR² = 0.015）。政策支持起到缓冲器作用：低政策支持下，工作压力显著抑制参与（B = -0.277, p = 0.005）；中高政策支持下，压力的负面影响被削弱至不显著。

## 分析方法

1. 描述性统计：均值、标准差、频率
2. 相关分析：皮尔逊相关系数及95%置信区间
3. 回归分析：多元线性回归、标准化系数
4. 中介效应分析：Baron and Kenny方法
5. 效应量分析：Cohen's d、R平方
6. **调节效应分析**：层次回归、简单斜率分析、Johnson-Neyman区间、Bootstrap稳健性检验

---

## 调节效应分析详情

我们对工作场所政策支持在工作压力与父亲家庭教育参与之间的调节作用进行了全面分析。

### 分析方法
- 层次回归分析（Aiken & West, 1991; Hayes, 2018）
- 连续变量均值中心化
- 在调节变量±1 SD处进行简单斜率分析
- Johnson-Neyman 显著性区间法
- Bootstrap 稳健性检验（5000次重抽样）

### 主要结果
- **交互效应**：B = 0.230, SE = 0.077, β = 0.124, t(567) = 2.997, p = 0.003, 95% CI [0.080, 0.381]
- **效应量**：ΔR² = 0.015, f² = 0.016（小效应）
- **模式**：缓冲型交互
  - 低支持（-1 SD）：工作压力显著降低参与（B = -0.277, p = 0.005）
  - 中等支持（均值）：无显著关系（B = -0.067, p = 0.354）
  - 高支持（+1 SD）：无显著关系（B = 0.142, p = 0.169）
